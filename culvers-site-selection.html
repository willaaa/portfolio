Culvers Site Selection

As the final project for Datasci 415: Data Mining and Statistical Learning, my partner and I applied concepts from the class to create a model predicting suitable locations for Culvers restaurants. We utilized logistic regression, collaborative filtering, K-means and isolation forest algorithms and achieved 90% accuracy in site selection. The full NeurIPS style report can be found here.
